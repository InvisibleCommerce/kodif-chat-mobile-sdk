# Changelog

## 0.1.0 (unreleased)

First version of Kodif Chat for iOS (`KodifChat`, Swift Package Manager) and Android (`ai.kodif:chat`, JitPack
`com.github.InvisibleCommerce:kodif-chat-mobile-sdk`): the Kodif chat widget full screen in a web view, with shopper
sign-in (a JWT token provider and `shopperChanged()`), links, voice mode, attachments, an unread-reply count and
preloading. Bridge protocol v1 (PROTOCOL.md).
