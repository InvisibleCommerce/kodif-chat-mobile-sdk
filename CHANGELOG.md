# Changelog

## 0.1.0 (unreleased)

First version of Kodif Chat for iOS (`KodifChat`, Swift Package Manager) and Android (`ai.kodif:chat`): the Kodif
chat widget full screen in a web view, with shopper sign-in (JWT token provider), links, voice mode, attachments,
unread-reply events and preloading. Bridge protocol v1 (PROTOCOL.md).
